# 🛒 딸랑구 (Ddallanggu)

> **"딸에게 전화하듯, 말로 맡기는 쇼핑 경험"**  
> 디지털 취약계층을 위한 음성 기반 AI 쇼핑 어시스턴트

---

## 📌 프로젝트 개요

**딸랑구**는 고령층 및 디지털 취약계층이 복잡한 쇼핑앱 UI 없이도,  
음성 대화만으로 상품 탐색부터 주문까지 스스로 완료할 수 있도록 돕는 **AI Agent 서비스**입니다.

> "저번에 맛있게 먹었던 딸기 다시 사줘"  
> → 딸랑구가 이전 구매 이력을 찾아 후보를 추려드립니다.  
> → 최종 확인 후 주문까지 연결됩니다.

---

## 🎯 해결하려는 문제

| 문제 | 설명 |
|------|------|
| 복잡한 UI | 작은 글씨, 정보 과부하로 원하는 상품을 찾기 어려움 |
| 결제 절차 | 본인인증, 간편결제 등록 등 복잡한 단계에서 이탈 |
| 구매 이력 분산 | 쿠팡, 네이버, 마켓컬리 등 플랫폼별로 이력이 흩어져 있음 |
| 심리적 부담 | 오류 메시지와 낯선 용어로 인한 두려움 → 가족에게 의존 |

---

## ✨ 핵심 기능

### 1. 🎙️ 음성 기반 구매 요청
복잡한 검색창 없이 자연어 음성으로 상품을 요청합니다.

```
"지난번에 산 참기름 다시 사줘"
"늘 사던 딸기 주문해줘"
```

### 2. 🔁 이전 구매 이력 기반 재구매 지원
모호한 표현("저번에 산 것", "맛있었던 것")을 구매 기록과 연결해 해석합니다.

### 3. 📊 상품 후보 요약 및 비교
검색 결과 전체가 아닌, 2~3개의 핵심 후보만 추려 가격·용량·배송일 중심으로 제시합니다.

### 4. ✅ 최종 확인 기반 주문 진행
AI가 임의로 결제하지 않고, 사용자의 명시적 확인 후 주문을 진행합니다.

```
딸랑구: "한 달 전에 주문했던 설향 딸기 500g을 바로 주문할까요? 가격은 9,900원이에요."
사용자: "응, 그걸로 구매해줘"
딸랑구: "주문 완료했어요! 😊"
```

### 5. 📝 구매 로그 및 상태 관리
요청 → 추천 → 선택 → 확인 → 주문 전 과정을 기록하여 개인화 추천에 활용합니다.

## 🏗️ 시스템 아키텍처

본 프로젝트는 **LLM + Tool + Memory + Orchestration** 구조의 Multi-AI Agent 시스템으로 구현합니다.

```
사용자 (음성/텍스트 입력)
        │
        ▼
┌─────────────────────────────────────────────────────┐
│                   Orchestrator Agent                 │
│         요청 분석 → 흐름 제어 → 응답 생성            │
└───────────┬───────────────────────┬─────────────────┘
            │                       │
            ▼                       ▼
┌───────────────────┐   ┌───────────────────────────┐
│   Search Agent    │   │      Order Agent           │
│  상품 탐색 및 비교 │   │  장바구니·주문 프로세스 처리 │
└───────────────────┘   └───────────────────────────┘
            │                       │
            └───────────┬───────────┘
                        │
            ┌───────────▼───────────┐
            │      Memory Layer      │
            │  ┌──────────────────┐  │
            │  │  Session Store   │  │  ← 현재 대화 문맥 (Redis)
            │  │  (단기 메모리)    │  │
            │  └──────────────────┘  │
            │  ┌──────────────────┐  │
            │  │  Memory Bank     │  │  ← 구매 선호·중요 이벤트 기록
            │  │  (장기 메모리)    │  │
            │  └──────────────────┘  │
            │  ┌──────────────────┐  │
            │  │   Database       │  │  ← 구매 이력·상품 데이터 (영구 저장)
            │  └──────────────────┘  │
            └───────────────────────┘
```

### 구성 요소 설명

| 구성 요소 | 역할 |
|-----------|------|
| **LLM** | 사용자 자연어 요청 이해 및 모호한 표현 해석 |
| **Tool** | 상품 검색 API, 구매 이력 조회 API, 주문 API 등 외부 연동 |
| **Memory** | 구매 이력, 선호 상품, 대화 맥락 저장 및 검색 |
| **Orchestration** | 요청 분석 → 탐색 → 비교 → 확인 → 주문 흐름 제어 |

## 🗃️ 데이터 설계

| 데이터 종류 | 포함 항목 |

| **구매 이력** | 상품명, 브랜드, 용량, 가격, 구매일, 플랫폼, 재구매 횟수, 만족도 |
| **상품 데이터** | 상품명, 카테고리, 가격, 옵션, 배송 가능 여부, 평점, 리뷰 요약 |
| **대화 로그** | 사용자 요청, Agent 응답, 추천 후보, 최종 선택 여부, 실패 원인 |

## 🚀 MVP 구현 흐름

```
1. 사용자 음성/텍스트 입력
        ↓
2. AI Agent → 요청 의도 분석
        ↓
3. 구매 이력 DB에서 관련 상품 탐색
        ↓
4. 후보 2~3개 요약 제시 (가격·용량·배송 중심)
        ↓
5. 사용자 최종 선택 및 확인
        ↓
6. 주문 완료 / 장바구니 담기 결과 반환
```

> MVP에서는 식료품·생필품 재구매 시나리오를 중심으로 구현하며,  
> 실제 결제 API 연동이 어려운 경우 가상 주문 시뮬레이션으로 대체합니다.

## ⚙️ 설치 및 실행

### 1. 저장소 클론

```bash
git clone https://github.com/your-team/ddallanggu.git
cd ddallanggu
```

### 2. 가상환경 설정 및 패키지 설치

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. 환경변수 설정

```bash
cp .env.example .env
# .env 파일에 API 키 입력
```

```env
ANTHROPIC_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here
REDIS_URL=redis://localhost:6379
DATABASE_URL=sqlite:///./ddallanggu.db
```

### 4. 서버 실행

```bash
uvicorn app.main:app --reload
```

### 5. API 문서 확인

```
http://localhost:8000/docs
```
