# 딸랑구 🛒
 
> **"말만 하면 대신 사드려요"**
> 어르신과 디지털 취약계층을 위한 음성 기반 AI 쇼핑 어시스턴트
 
---
 
## 소개
 
딸랑구는 복잡한 앱 화면 없이, 말 한마디로 온라인 쇼핑을 완료할 수 있는 서비스입니다.
음성 명령만으로 상품 검색부터 결제까지 처리하며, 어르신도 쉽고 편안하게 사용할 수 있도록 설계되었습니다.
 
---
 
## 주요 기능
 
- 🎙️ **음성 기반** — 딸에게 전화를 걸듯 편하게 말로 소통해요
- 🛍️ **멀티 플랫폼 연동** — 네이버 쇼핑, 쿠팡, 마켓컬리 등 여러 플랫폼에서 통합 검색이 가능해요
- 🤖 **상품 추천** — 개인의 취향에 맞는 상품을 선별하여 추천해요
- 🔒 **간단한 구매** — 장바구니 담기, 옵션 선택 등 복잡한 단계를 딸랑구가 도와줘요
